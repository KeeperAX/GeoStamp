# GeoStamp

**GeoStamp** — веб-сервис для поиска местных заведений, подтверждения посещений и публикации отзывов на основе реального опыта. Пользователи смогут отмечать посещённые места, собирать уникальные штампы, получать достижения и участвовать в рейтинге посетителей.

**Статус:** проект находится в разработке.

## Цель проекта

Создать сервис, который помогает знакомиться с заведениями города и повышает доверие к отзывам: оставлять отзыв можно будет только после подтверждённого посещения.

## Основные возможности

В проекте предусмотрены следующие функции:

- регистрация и авторизация пользователей;
- интерактивная карта заведений с информацией о каждом месте;
- поиск и фильтрация заведений;
- подтверждение посещения с помощью одноразового восьмизначного кода заведения;
- публикация отзывов после подтверждённого посещения;
- личный кабинет с историей посещений и коллекцией штампов;
- достижения и рейтинг посетителей;
- управление заведениями и справочниками через административный интерфейс.

> Часть функций ещё находится на этапе проектирования и разработки.

## Локальный запуск

### 1. Получение проекта

```bash
git clone https://github.com/KeeperAX/GeoStamp.git
cd GeoStamp
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка базы данных

Установите PostgreSQL, создайте локальную базу данных и настройте параметры подключения в `geostamp/geostamp/settings.py` (раздел `DATABASES`): имя базы, пользователь, пароль, хост и порт.
